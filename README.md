# 3인칭 액션 게임

Unity와 C#을 활용하여 1인 개발한 3인칭 액션 게임입니다.

## 주요 기능

- 플레이어 이동 및 점프
- 걷기 / 달리기 및 스태미나 시스템
- 공격 콤보 및 가드 시스템
- NavMeshAgent 기반 몬스터 AI
- 무기 Collider 기반 공격 판정
- 락온 타겟팅 시스템
- Cinemachine 기반 3인칭 카메라
- Animator Blend Tree 기반 이동 애니메이션
